# m3tal-smart Documentation

`m3tal-smart` is a planned smart disk telemetry plugin.

## Planned scope

Drive health telemetry, NVMe wear life, S.M.A.R.T. self-tests, and temperature history.

## Status

Planned. No `plugin.yaml`, implementation, or release workflow exists yet. When implemented, it should use `Build-m3tal-smart-Deb.yml` and publish `m3tal-plugin-smart` through `m3tal-apt-key`.

See the plugin [`README.md`](../README.md) and repository [`PLUGINS.md`](../../PLUGINS.md).
