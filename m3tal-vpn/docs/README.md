# m3tal-vpn Documentation

`m3tal-vpn` is a planned VPN tunnel plugin.

## Planned scope

WireGuard/OpenVPN tunnel connectivity with container egress routing and leak protection.

## Status

Planned. No `plugin.yaml`, implementation, or release workflow exists yet. When implemented, it should use `Build-m3tal-vpn-Deb.yml` and publish `m3tal-plugin-vpn` through `m3tal-apt-key`.

See the plugin [`README.md`](../README.md) and repository [`PLUGINS.md`](../../PLUGINS.md).
