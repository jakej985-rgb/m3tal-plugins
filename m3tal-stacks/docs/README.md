# m3tal-stacks Documentation

`m3tal-stacks` is a planned Compose template database plugin.

## Planned scope

Curated database of verified Docker Compose templates, argument presets, and 1-click community stacks.

## Status

Planned. No `plugin.yaml`, implementation, or release workflow exists yet. When implemented, it should use `Build-m3tal-stacks-Deb.yml` and publish `m3tal-plugin-stacks` through `m3tal-apt-key`.

See the plugin [`README.md`](../README.md) and repository [`PLUGINS.md`](../../PLUGINS.md).
